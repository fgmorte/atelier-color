En esta primera versión puedes importar fotografías o dibujos para colorearlos libremente. Las láminas de demostración incluyen además el modo de coloreado por números.

ATELIER COLOR · DEMO 0.1

Tu colección permanece contigo.

Esta aplicación funciona sin cuentas, sin publicidad y sin enviar tus imágenes a ningún servidor.

Coloreado por números: selecciona un color y toca las zonas que llevan ese número.

Coloreado libre: importa una imagen y pinta sobre ella con el dedo o el ratón.

Privacidad: las imágenes importadas y el progreso se almacenan localmente en este navegador. Si borras sus datos, perderás las obras guardadas; exporta tus resultados para conservarlos.

Para que la aplicación funcione sin conexión, ábrela primero con Internet y espera a que termine de cargar. Requiere GitHub Pages o un servidor HTTPS para instalar el Service Worker.
